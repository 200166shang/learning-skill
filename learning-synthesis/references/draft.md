# Draft

Read [LearningRecord](../../_shared/learning-record.md) before drafting. Use [LearningSynthesisState](../../_shared/learning-synthesis-state.md) for topic decisions/indexes; load the KnowledgeTicket contract only for a separate Ticket operation.

Require a confirmed Map. Inventory how existing materials support its nodes, then create/update one publishable mother-document LearningRecord with `record_type: synthesis`. Organize it around the central question and coherent explanatory thread, keep prerequisites minimal, and distinguish evidence, inference, and unresolved gaps. The mother-document artifact itself records that drafting has occurred.

When revising an existing synthesis-owned mother document, revise that same LearningRecord in place under the shared revision contract, preserving still-correct content and artifact identity.

Done when the mother document is independently readable, follows one coherent thread over the selected Map scope, uses available material for supported claims, leaves unresolved gaps explicit, and—on revision—remains at the same durable path.
