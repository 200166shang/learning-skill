# Curate

Keep living documents convergent without changing the active route. During learning, limit hygiene to touched documents; never run global curation after a child. Before root closure, inspect the touched set for duplicate concepts, mixed scopes, stale content, and unsupported semantic links.

When ownership and overlap are unambiguous, consolidate mechanically and use the deterministic runtime's explicit old→new mapping to update affected Journey and KnowledgeTarget refs. Ask the learner before destructive restructuring or when semantic ownership is ambiguous. Preserve stable paths where practical.

Refresh `OVERVIEW.md` only when the supported document map materially changes. Curation never changes State, creates Questions, or infers Evidence.
